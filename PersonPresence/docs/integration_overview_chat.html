1. Stack at a Glance

2. What is TinyEngine?

TinyEngine is the inference runtime from the MCUNet project. It combines TinyNAS-generated networks with aggressive MCU-specific optimizations such as static memory scheduling, operator fusion, in-place depthwise convolution, and patch-based execution.

In-place Depthwise

Reduces activation memory by reusing buffers.

Patch Inference

Processes image regions incrementally to reduce SRAM pressure.

Operator Fusion

Combines kernels and quantization steps.

Static Scheduling

No malloc and no runtime planner.

6. MCU Integration

  1. OV7670 captures RGB565 frames.
  2. DMA fills frame buffer.
  3. VSYNC signals frame ready.
  4. Preprocessing center-crops and resizes to 64×64.
  5. getInput() → invoke(NULL) → getOutput()
  6. EMA smoothing and hysteresis produce final state.
  7. USB CDC streams metadata and image data to dashboard.
